## 1. 动机与背景

### 1.1 原始 O-Voxel 的局限

TRELLIS.2 的原始 O-Voxel（Flexible Dual Grid）每个体素存储：

- **1 个对偶顶点**（体素内的 3D 位置）
- **3 个二值穿越标志**（每个轴一个：曲面是否穿过该边？）
- **1 个分割权重**（四边形→三角形的分割方向）

这种表征存在根本性的局限：

1. **二值边穿越**：一条边要么被穿过、要么没有——无法表示曲面多次穿过同一条边（例如多层几何体、折叠布料）。
2. **每体素单顶点**：无法表示单个体素内存在多片互不相连的曲面。
3. **矩形面歧义**：即使将穿越扩展为计数（0…n），矩形面仍然存在歧义——例如十字交叉与两条平行斜线在矩形面上的边穿越计数完全相同，无法区分。
4. **无边界/U-Turn 处理**：开曲面（边界）和在面内掉头的曲线（U-Turn）无法被表征。

### 1.2 我们的方案：CoReP

CoReP 通过以下方式解决上述局限：

1. **多重穿越边编码**（0…n 整数代替 0/1 二值）
2. **三角化 Cube 面**（6 条对角线消除矩形歧义）
3. **法曲线理论**实现拓扑保证的环重建
4. **面权重**处理 U-Turn 和开边界
5. **每体素多个分支点**（每个拓扑环对应一个顶点）

## 2. 表征设计

### 2.1 每 Cube 的特征向量

每个被占据的 Cube 存储以下特征：

| 特征 | 维度 | 类型 | 说明 |
|------|------|------|------|
| `num_components` | 1 | int | 该 Cube 内连通曲面分支的数量 |
| `num_boundary` | 1 | int | 该 Cube 内的开边界数量 |
| `edge_weights` | 18 | int[] | 18 条边各自的穿越次数（12 条原始边 + 6 条对角线） |
| `face_weights` | 12 | int[] | 12 个三角面片上的 U-Turn + 开边界计数 |
| `component_points` | n×3 | float[] | 每个拓扑分支的 3D 质心（n = num_loops） |

### 2.2 有效存储：6 维边编码

虽然每个 Cube 计算 18 个边权重，但共享边将全局唯一存储量降低：

- **12 条原始 Cube 边**：每条边被 **4** 个相邻 Cube 共享 → 12/4 = **3** 个唯一值
- **6 条对角线**：每条对角线被 **2** 个相邻 Cube 共享 → 6/2 = **3** 个唯一值
- **每 Cube 唯一总量**：**6 维**整数边数据

这是一个关键洞察：18 维的局部表征在全局去重后坍缩为 6 个唯一维度。

### 2.3 为什么要三角化？—— 消除矩形歧义

考虑一个矩形面，对边各被穿过两次（edge_weight = 2）：

```
    穿过 2 次              穿过 2 次
  ─────×──×─────       ─────×──×─────
  |     ╲╱     |       |    ║  ║    |
  |     ╱╲     |  vs   |    ║  ║    |
  ─────×──×─────       ─────×──×─────
    穿过 2 次              穿过 2 次
```

左边的模式（X 型交叉）和右边的模式（平行穿过）在矩形面上的边穿越计数完全相同——**它们是歧义的**。添加一条对角线将矩形分割为两个三角形后，对角线的穿越计数就能区分这两种情况。

在**三角形**上，**三角不等式**和**奇偶性法则**（3 条边权重之和必须为偶数）共同保证了唯一的、非交叉的弧分配——这正是**法曲线理论（Normal Curve Theory）**的基础。

### 2.4 面权重：U-Turn 与开边界

即使有了三角化面，仍有两种现象无法仅通过边穿越来捕获：

1. **U-Turn（掉头）**：一条曲线从三角形的**同一条边**进入并退出，在面内掉头。这消耗了一条边上的 2 次穿越，但不穿过另外两条边。

2. **开边界（Open Boundary）**：一条曲线进入三角形后在其内部终止（位于开放网格边界处）。这消耗了一条边上的 1 次穿越，但没有对应的出口。

`face_weights[f]` 整数记录了三角面片 `f` 上此类特殊事件的总数。由于 U-Turn 和开边界不太可能同时出现在同一个面上，它们共用这个整数值。二者的区分可以通过以下方式推断：
- 边穿越奇偶性（U-Turn 消耗成对穿越；边界消耗单次穿越）
- 全局边界计数一致性（开端点总数必须为偶数）

## 4. 阶段一：体素化

**文件**：`voxelize.py`（约 560 行）

### 4.1 网格归一化

`normalize_mesh(mesh)` 将输入网格变换到 [0,1]³ 单位立方体内：

1. 合并重复顶点，移除退化/重复面
2. 居中到原点，均匀缩放使最大维度 = 1
3. 施加微量缩放（0.947×）和偏移，确保网格稳定位于网格内部而不触碰边界

### 4.2 拓扑特征提取

体素化之前，先提取拓扑特征：

- **`extract_boundaries(mesh)`**：查找**开边界边**——只属于一个三角形的边。这些边标示着开曲面（非水密网格）。返回边的顶点对数组。

- **`extract_non_manifolds(mesh)`**：检测**非流形边**（被 >2 个三角形共享）和"领结"顶点（网格在此处捏合）。这些需要在重建时特殊处理。

### 4.3 面到网格的注册

`process_face_to_grid(mesh, res, save_dir)` 将每个网格三角形映射到与之相交的体素 Cube：

**算法：分离轴定理（SAT）**

对每个三角形，测试它与候选 Cube AABB 的相交情况：

1. 计算三角形包围盒以确定候选 Cube
2. 对每个候选 Cube，测试 13 条分离轴：
   - 1 条三角形法线轴
   - 3 条 AABB 面法线轴（x, y, z）
   - 9 条叉积轴（3 条三角形边 × 3 条 AABB 轴）
3. 若不存在分离轴 → 三角形与 Cube 相交 → 注册

实现采用**向量化**：一个三角形的所有候选 Cube 通过 numpy 广播同时测试。

**输出**：每个被占据 Cube 一个 `face_register` 字典：
```python
{
    'cube_indices': (ix, iy, iz),
    'face_indices': [f0, f1, f2, ...]  # 与该 Cube 相交的三角形索引
}
```

### 4.4 边界与非流形注册

与面注册类似，但用于边界边和非流形特征：
- `process_boundary_to_grid()`：使用线段-AABB SAT 测试
- `process_non_manifolds_to_grid()`：注册非流形边和顶点

## 5. 阶段二：体积特征

**文件**：`feature_volume.py`（约 300 行）

### 5.1 连通分支分析

对每个 Cube，我们需要知道其中存在多少**不相连的曲面分支**。这决定了：
- 预期提取多少个环
- 需要多少个分支点

**算法**：在预计算的面邻接图上进行 DFS

1. **预计算邻接关系**：构建全局映射 `adj[face_i] = [face_j, face_k, ...]`，其中面之间共享网格边则视为邻接。这对整个网格只计算一次。

2. **逐 Cube DFS**：对每个 Cube 的 `face_indices` 集合：
   - 将邻接关系限制为仅该 Cube 内的面
   - 运行 DFS 计数连通分支
   - 存储结果为 `num_components`

3. **并行化**：使用 `multiprocessing.Pool`，通过 `_init_worker` 传递邻接图以避免逐进程复制。

**两种变体**：
- `volume_feature_face()`：用于内部面注册
- `volume_feature_boundary()`：用于边界边注册（使用边邻接而非面邻接）

## 6. 阶段三：边特征

**文件**：`feature_edge.py`（约 250 行）

### 6.1 Möller-Trumbore 边穿越计数

对每个 Cube，使用 Möller-Trumbore 射线-三角形相交算法计算全部 18 条边的穿越次数。

**每条边、每个三角形的计算过程**：

```
给定：射线起点 O，方向 D = (终点 - 起点)
      三角形顶点 V0, V1, V2
      E1 = V1 - V0, E2 = V2 - V0

P = D × E2
det = E1 · P

若 |det| < ε：射线与三角形平行 → 无交点

inv_det = 1 / det
T = O - V0
u = (T · P) × inv_det        // 重心坐标 u

若 u < 0 或 u > 1：未命中

Q = T × E1
v = (D · Q) × inv_det        // 重心坐标 v

若 v < 0 或 u + v > 1：未命中

t = (E2 · Q) × inv_det       // 射线上的参数距离

若 -ε ≤ t ≤ 1+ε：命中 → edge_weights[edge] += 1
```

**向量化**：Cube 内所有三角形对每条边同时测试，使用 numpy 数组运算，避免了 Python 层面的逐三角形循环。

**输出**：`edge_weights = [w0, w1, ..., w17]`——每条边的整数穿越计数。

18 条边对应：
- 边 0–11：原始 12 条 Cube 边
- 边 12–17：6 条面对角线（每个正方形面一条）

## 7. 阶段四：面特征与点特征

**文件**：`feature_face.py`（约 350 行），`feature_point.py`（约 200 行）

### 7.1 面权重计算

面权重捕获单靠边权重无法表征的 U-Turn 和开边界。

**算法**：对每个 Cube，对其 12 个三角面片中的每一个：

1. 取出注册到该 Cube 的所有网格三角形
2. 用 6 个 Sutherland-Hodgman 裁剪平面将每个网格三角形**裁剪**到 Cube AABB 内
3. 进一步分类裁剪后的多边形属于哪个三角面片
4. 计算每个连通分支的面积加权质心

`face_weights[f]` 记录面片 `f` 上特殊拓扑事件（U-Turn + 开边界）的数量。

### 7.2 Sutherland-Hodgman 多边形裁剪

`clip_polygon_against_plane(polygon, plane_normal, plane_point)`：

对多边形中每对相邻顶点 (p1, p2)：
- 若 p1 在内侧：保留 p1
- 若边 (p1→p2) 穿过裁剪平面：添加交点
- 对全部 6 个 AABB 平面重复

这将任意凸多边形裁剪到 Cube 边界内，得到每个网格三角形在 Cube 内的部分。

### 7.3 分支点提取

`feature_point.py` 计算 Cube 内每个连通分支的**质心**：

1. 识别连通分支（与体积特征相同的 DFS）
2. 对每个分支，收集其全部网格三角形
3. 将每个三角形裁剪到 Cube AABB（Sutherland-Hodgman）
4. 三角化裁剪后的多边形，计算面积加权质心
5. 输出：`component_points = [[x, y, z], ...]`——每个分支一个

这些质心将作为重建网格的**原始顶点（Primal Vertex）**。

## 8. 阶段五：基于法曲线理论的环提取

**文件**：`collapse_edge.py`（约 226 行）

这是核心拓扑算法。给定 18 个边穿越计数，它重建 Cube 表面上**精确的闭合环集合**。

### 8.1 法曲线理论背景

三角化曲面上的**法曲线（Normal Curve）**是满足以下条件的闭合曲线：
1. 横截地穿过每条边（无切点）
2. 不自相交
3. 在每个三角形内，由连接不同边上点的**弧**组成

核心定理：**给定三角化曲面上的合法边权重，每个三角形内的非交叉弧配置是唯一的。**

### 8.2 合法性验证

重建之前，验证边权重的一致性：

对每个三角形 (e1, e2, e3)，权重为 (w1, w2, w3)：
- **三角不等式**：w1 + w2 ≥ w3，w2 + w3 ≥ w1，w3 + w1 ≥ w2
- **奇偶性法则**：(w1 + w2 + w3) 必须为偶数

若任一条件不满足，则权重不一致，不存在合法环。

### 8.3 弧分配（逐三角形）

对合法三角形，权重为 (w1, w2, w3)：

```
k12 = (w1 + w2 - w3) / 2   — 连接 e1 ↔ e2 的弧数
k23 = (w2 + w3 - w1) / 2   — 连接 e2 ↔ e3 的弧数
k31 = (w3 + w1 - w2) / 2   — 连接 e3 ↔ e1 的弧数
```

这些值是唯一且非负的（由三角不等式保证）。

### 8.4 非交叉点配对

在每个三角形内，对每对边 (eA, eB)，需要连接 k 条弧：

1. 找到 eA 和 eB 的公共顶点 `v`
2. 在 eA 上取距 v 最近的 k 个穿越点 → `pts_A`
3. 在 eB 上取距 v 最近的 k 个穿越点 → `pts_B`
4. 逐对连接：`pts_A[i] ↔ pts_B[i]`，i = 0..k-1

这种"最近对最近"的配对保证了**弧不交叉**——法曲线的根本性质。

### 8.5 环追踪

分配完所有弧后，构建图：
- 节点 = 每个穿越点的 `(edge_idx, point_idx)`
- 图边 = 连接配对点的弧

每个节点恰好度为 2（每个穿越点恰好连接来自相邻三角形的两条弧）。通过以下方式追踪环：

1. 从任意未访问节点出发
2. 沿图边前进，始终选择不是刚来的方向的邻居
3. 直到回到起点 → 一个闭合环
4. 对剩余未访问节点重复

**输出**：`loops = [[e0, e1, e2, ...], ...]`——每个环是其穿过的边索引序列。

## 9. 阶段六：U-Turn 与开边界消解

**文件**：`collapse_face.py`（约 500 行）

当面权重非零时，仅基于边的环提取（阶段五）不充分。需要处理 U-Turn 和开边界。

### 9.1 内部 Cube：U-Turn 消解 (`extract_loops_with_uturns`)

对于无开边界的 Cube（所有曲面都是闭合的）：

**步骤一 — 局部枚举**：对每个三角形 (e1, e2, e3)，面权重 W：
- 枚举所有 (u1, u2, u3) 使得 u1 + u2 + u3 = W
- 每个边 eX 上的 U-Turn 消耗 edge_weights[eX] 的 2 次穿越
- 计算调整后权重：w'i = wi - 2·ui
- 验证调整后权重满足三角不等式 + 奇偶性

**步骤二 — 全局笛卡尔积**：将 12 个面的合法局部分配进行组合。对每种全局分配：
- 构建包含普通弧 AND U-Turn 弧的邻接图
- U-Turn 弧连接同一条边上的相邻点对：`(e, p) ↔ (e, p+1)`
- 按阶段五的方式追踪环

**步骤三 — 去重**：对环进行标准化（循环旋转 + 反转），识别唯一解。

**步骤四 — 分类**：
- **已解（Solved）**（1 个唯一解）：存储环
- **歧义（Ambiguous）**（≥2 个解）：存储所有候选（可能需要外部消歧）
- **不可解（Unsolvable）**（0 个解）：标记为异常

**剪枝**：任何单个面索引在环中出现 ≥3 次的解被拒绝（反向 U-Turn——物理上不可能）。

### 9.2 边界 Cube：开边界消解 (`extract_loops_with_boundaries`)

对于包含开网格边界的 Cube，枚举扩展为每条边每个三角形上的三类弧：

- **k-弧**：正常的跨三角形连接（与阶段五相同）
- **U-Turn 弧**：同边掉头对
- **边界弧**：在三角形内终止的单端点

对每个三角形面：
```
对边 E，权重 W：
    k_used = 消耗该边的 k-弧数
    remaining = W - k_used
    remaining = 2·u + b  （u 个 U-Turn + b 个开边界）
```

面权重目标 B_target = 该三角形 3 条边上 (u + b) 的总和。

**全局约束**：所有面上开边界端点的总数必须为偶数（每条开路径有两个端点）。

环追踪同时处理闭合环和开路径：
- **开路径**从 "bound" 节点（边界端点）开始和结束
- **闭合环**从剩余未访问的 port 节点追踪

## 10. 阶段七：环排序与点分配

**文件**：`collapse_point.py`（约 500 行）

### 10.1 环排序：Rank 分配 (`sort_loops_in_cube`)

当多个环穿过同一条边时，我们需要知道它们在该边上的**顺序**（rank 0 = 距第一个顶点最近，rank W-1 = 距第二个顶点最近）。

该算法重建法曲线邻接图（与阶段五相同），但保留显式的 rank 信息：

1. 构建节点为 `(edge, rank)` 的邻接图
2. 追踪环得到 `(edge, rank)` 对的序列
3. 将追踪到的环与输入环进行边序列匹配（正向和反向匹配）
4. 输出：`sorted_loops = [{'loop': [...], 'rank': [...]}, ...]`

### 10.2 点到环的分配：匈牙利算法

每个环需要恰好一个 `component_point`。若有 n 个环和 n 个分支点，这是一个二部匹配问题。

**算法**：

1. **计算环质心**：对每个环，取其所有边穿越点 3D 位置的平均值。穿越点 (edge, rank) 在边 (u, v) 上的位置为：
   ```
   t = (rank + 1) / (W + 1)
   position = vertex[u] + t × (vertex[v] - vertex[u])
   ```

2. **构建代价矩阵**：C[i,j] = loop_i 质心与 component_point_j 之间的欧氏距离平方

3. **用 `scipy.optimize.linear_sum_assignment` 求解**：O(n³) 匈牙利算法找到最小代价完美匹配

4. **分配**：每个环获得其匹配的 `component_point`

这确保每个拓扑环与几何上最近的曲面分支质心相关联。

## 11. 阶段八：全局网格重建

**文件**：`collapse.py`（约 1300 行）

### 11.1 数据重组

网格生成前，逐 Cube 的数据被重新组织：

- `reform_intersection_data()`：将每个环与其分配的 component_point 配对
- `extract_original_cube_edges()`：过滤环仅保留原始 12 条 Cube 边（对角线是辅助性的——它们帮助拓扑判定但不定义跨 Cube 连接）

### 11.2 全局边坐标系

每条原始 Cube 边被映射到一个**全局边标识符**：

```
get_global_edge(ix, iy, iz, local_edge) → (axis, nx, ny, nz)
```

其中 `axis ∈ {x, y, z}`，`(nx, ny, nz)` 是边的全局网格坐标。这实现了共享边的去重：4 个相邻 Cube 可能引用同一条物理边。

### 11.3 共享边处理 (`process_shared_edge_geometry`)

每条全局边最多被 4 个排列成 2×2 网格的 Cube 共享。网格重建发生在这些共享边处：

**对每条共享边、每个 rank**：

1. 从 4 个相邻 Cube 中收集在该边该 rank 处有环穿过的 `component_point`
2. 计算这些点的**平均值** → `proj_pt`（共享边上的投影点）
3. 若 4 个点都存在，创建**4 个三角形**组成扇形配置：
   ```
   Triangle(proj_pt, point[0,0], point[1,0])
   Triangle(proj_pt, point[1,0], point[1,1])
   Triangle(proj_pt, point[1,1], point[0,1])
   Triangle(proj_pt, point[0,1], point[0,0])
   ```

这在每条边周围创建了一个局部光滑的四边形片，连接 4 个 Cube。

**异常 Cube 处理**：环提取失败的 Cube（歧义/不可解）被视为通配符——其第一个 component_point 被注入到缺少该位置点的任何 rank 组中。

**Rank 归一化**：由于不同 Cube 可能以相反方向索引同一条边，rank 被归一化到一致的全局朝向（边 2、6、3、7 被反转）。

### 11.4 基于字典序的任务分配

为避免每条边被处理 4 次（每个相邻 Cube 一次），我们使用**字典序所有权**：

> 一条边仅由其活跃邻居中字典序最小的 Cube 处理。

这保证每条边恰好被处理一次，无需维护全局"已处理"集合——O(1) 内存开销。

### 11.5 流式写盘网格生成

网格的生成不在内存中累积所有顶点/面：

1. **任务生成器**：惰性地为每条共享边产生 2×2 网格配置
2. **顶点流式写入**：新顶点立即写入 `.verts.tmp` 文件
3. **面流式写入**：新面立即写入 `.faces.tmp` 文件
4. **动态顶点焊接**：坐标四舍五入到 `merge_decimals` 精度；空间哈希映射将舍入后坐标映射到顶点索引
5. **面去重**：标准化绕向顺序防止重复三角形
6. **PLY 组装**：头部 + 顶点 + 面合并为最终 ASCII PLY 文件

## 15. 核心算法速查

| 算法 | 文件 | 用途 |
|------|------|------|
| **分离轴定理 (SAT)** | voxelize.py | 三角形-AABB 和线段-AABB 相交测试 |
| **Möller-Trumbore** | feature_edge.py | 射线-三角形相交，用于边穿越计数 |
| **Sutherland-Hodgman 裁剪** | feature_face.py, feature_point.py | 将网格三角形裁剪到 Cube AABB |
| **邻接图上的 DFS** | feature_volume.py | 连通分支计数 |
| **法曲线理论 (Normal Curve Theory)** | collapse_edge.py | 拓扑保证的环重建 |
| **U-Turn 枚举** | collapse_face.py | 面权重分配的组合搜索 |
| **匈牙利算法** | collapse_point.py | 最优二部匹配（环 ↔ 点） |
| **字典序所有权** | collapse.py | O(1) 内存的边去重 |
| **流式写盘生成** | collapse.py | 内存有界的网格输出 |
| **PCA 平面拟合** | collapse_volume.py | 局部曲面朝向的调试可视化 |

### 性能优化

- **向量化 SAT/Möller-Trumbore**：Numpy 广播消除逐三角形的 Python 循环
- **多进程并行**：所有特征提取阶段使用 `multiprocessing.Pool`，通过只读共享数据
- **批次处理**：有上限的批次大小防止 IPC 内存溢出
- **惰性任务生成**：边处理使用生成器，避免一次性具化所有任务
- **流式 I/O**：网格直接写盘，不累积完整的顶点/面数组
- **空间哈希**：网格生成时 O(1) 的顶点去重
